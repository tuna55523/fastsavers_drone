# Project Overview
This project is an Autonomous Rescue Drone AI System designed to detect and analyze humans in water environments and estimate drowning risk in real time.

The system runs on a DJI Tello drone using computer vision and behavioral analysis.

## Main objectives

- Detect humans in water
- Analyze behavior over time
- Estimate drowning risk
- Track individuals consistently
- Follow the highest-risk target
- Provide manual and autonomous drone control modes

The system is currently tested indoors using videos on a monitor, but the architecture is designed for real-world ocean/lifeguard scenarios.

## Current System Behavior

### Works correctly for:
- detecting humans
- tracking individuals
- estimating risk
- ignoring non-human objects

However the drowning estimation still needs improvement.

### Current limitations:
- Swimming vs drowning confusion
- Panic motion detection needs tuning
- Risk thresholds may need calibration
- No pose analysis yet
- No temporal posture analysis
